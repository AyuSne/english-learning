# 首版产品范围

更新日期：2026-11-16。

本文件记录已确认的产品范围。后续规划与实现以此处的最新决定为准；调研报告中的题型、题目与答案分析属于历史材料研究，不自动构成功能要求。

## 已确认

- 首版面向六级备考，使用平台为 Windows。
- 核心围绕文章和单词之间的联系：阅读文章、主动选词、保留原句与完整原文的关联，并在复习时回到阅读语境。
- 选词由学习者发起，支持单个词和短语；既包括不认识的表达，也包括认识但觉得值得学习的表达。
- 复习可以从词汇记录回到原文，也可以通过重读原文再次遇见所选词。
- PDF 是当前重点讨论的文章来源。导入目标调整为整理可阅读、可选词、可回查来源的文章。
- 首批材料限定为 2023—2026 年的 21 份六级 PDF，逐份清单及 SHA-256 见 [首批材料清单](./first-batch-pdfs.json)。
- 首批正文范围为仔细阅读和长篇匹配的完整英文文章。题干、选项、考试说明、答案和解析不进入文章库。
- 本轮仍以形成双方认可的首版产品说明为目标。

## 已确认的阅读与选词体验

- 主要阅读界面显示重新排版的文章正文，支持调整字号和行距，并保留打开原 PDF 对照的入口。
- 默认沿用先阅读圈词、后集中查词的节奏。阅读时圈选词或短语，正文做高亮，并保存对应原句与出处。
- 读完文章后可进入本篇选词列表，集中查词和整理学习内容。

## 已确认的阅读界面与原文对照

- 阅读界面单栏居中，正文宽约 720px；字号 16/18/20/22 四档、行距 1.6/1.8/2.0 三档，设置随用户记住。
- 长篇匹配在段首显示原卷段落字母（A–P），仔细阅读不显示；暂不做侧边段落导航。
- 原文注释默认以浅色小字显示在原词后，可一键隐藏、状态记住；选词、复制与交给模型的文本使用剥离注释后的正文。
- 原 PDF 以右侧抽屉内嵌（pdf.js），可拖动宽度，窄窗口下改为覆盖层；从原句进入时跳到所在页并高亮该句，定位失败依次退到段落、页并提示。
- 记住每篇最后读到的段落与句子；文章列表按 7 个场次分组，显示题型、词数与该篇阅读进度；首页提供“继续阅读”。
- 文章底部的“进入本篇选词”视为读完该篇，不单独维护“已读”状态。

## 已确认的词条组织与收集体验

- 同一个词或短语归到一个词条下，词条关联多条来自不同阅读语境的原句，分别保留出处与返回文章的关系。
- 常见词形变化归到同一词条，例如 approach、approached、approaching；原句和其中的实际词形保留原样。approachable 这类派生词独立成词条。
- 同一篇文章、同一句话中重复圈选同一表达，只保留一条原句关联；遇见新的原句时增加收藏。
- 原句不断积累的“收集感”是用户特别强调的核心体验。词条展示已收集原句条数和来源文章数；每次新增时，清楚展示刚收下的原句。

## 已确认的词条浏览与修改

- 原句按文章分组，组内按句序；组头显示篇名与该篇贡献的条数。
- 每条原句提供：回到原文、重新圈定（替换选错的范围）、删除；同篇前后句悬浮展开查看。
- 选错范围只能重新圈选，不直接编辑原句文字，保证原句与原文逐字一致。
- 词条页的“更多”里可合并词条、把某条原句拆到新词条或另一个词条、更换主词形。
- 词条列表默认按最近收集排序，可切换字母序；搜索同时匹配词条名与已收原句文本；筛选先做“有/无学习内容”。
- 删掉最后一条原句时，提示后连同该词条的学习内容一并删除。

## 已确认的学习内容与生成文章整理

- 词条页里已保存的学习内容可就地编辑（点击编辑、保存后按 Markdown 渲染），可删除、可置顶一条；不保留历史版本，保存后以最终稿为准。
- 学习内容可移到另一个词条，入口与“把原句拆到…”并列在词条页的“更多”里。
- 搜索覆盖词条名、已收原句文本、学习内容正文与生成文章正文；结果按“词条 / 文章”分组，点进去落到命中位置。
- 文章库里生成文章与真题文章同列，但标“AI 生成”，可按来源筛选真题 / AI；可重命名、删除；不做标签体系。

## 已确认的 LLM 辅助方向

- LLM 接受学习者自己的要求，任务和输出形式保持可定制，不将学习辅助固定为统一的语境词义讲解。
- 学习对象可以是一个词、短语、原句，或学习者选定的一组词。
- 用户希望按需获得词义、简单例句、相近短语、近义词、多义词说明、各种助记，以及包含多个目标词的文章等学习内容。
- 用户可保存自己的常用学习指令，之后调用、修改和复用。
- 生成结果先展示，由用户挑选、修改后保存到对应词条；用户可以继续生成或改写，再留下喜欢的内容。
- 用一组词生成的文章可以保存到文章库，明确标注“AI 生成”，并支持阅读、选词和回链。
- 首批外部导入材料仍为既定 21 份 PDF；生成文章是围绕所收词汇制作的学习材料，不扩展外部 PDF 范围。
- 各类学习内容保留来源信息。AI 直接生成的例句属于生成内容；在生成文章中阅读选词形成的原句记录，以该生成文章为来源。

## 已确认的学习指令与生成流程

- 学习指令是自由文本，旁挂几条内置示例（词义与用法、例句、近义辨析、助记、多义词、生成文章）可一键填入；不锁定格式，不使用占位符语法。
- 保存的指令有名称，可修改、删除、复制；调用时以保存的指令为起点继续编辑。
- 上下文面板固定在输入框上方：默认带所选词与对应原句，其他原句、段落与笔记可勾选加入，每项可单独移除，顶部显示“N 条原句 · 约 M 字”。
- 生成结果用版本式结果卡：重新生成或改写产生新版本，可在卡上切换；输出达到模型上限时可“继续生成”，新内容接在同一版本后。
- 生成过程中发送键变成停止键，输入区不锁死；停止或出错时保留已输出内容，可保存但要标“未完成”；重试从头发起，不自动重试。
- 保存去向只有两处：保存到词条作为学习内容，或显式选择“存为文章”进入文章库，不按长度或内容自动判断。
- 一次可对一组词生成：词条列表多选后“用这些词学习”，或在自由学习里添加词条；一次最多 20 个。
- 错误按类型给具体提示与动作（更换密钥、余额不足、限流、服务繁忙、网络异常），只有可重试的错误显示重试。

## 已确认的自主复习与学习上下文

- 软件提供文章、词条、原句、个人学习内容和 LLM 工具的平台，复习内容与使用方式由学习者自主组合，不强制一条固定复习路线。
- 打开词条时默认先展示已收集的原句，释义、助记等学习内容可展开查看。默认展示顺序不限制用户采用其他复习方式。
- 调用 LLM 时，默认带上学习者选中的词和原句；其他原句、文章段落与已保存笔记由学习者选择是否加入。
- 学习上下文可查看、可选择，便于学习者控制模型这次参考的材料。

## 已确认的复习与重读

- 首页三块：继续阅读（最近一篇没读完的）、最近收集的词条、进文章库的入口；不做统计仪表盘与学习时长。
- 提供手动“稍后看”标记，首页单列显示；不做按时间或遗忘曲线的自动排程。
- 重读原文时，本篇收过的表达做弱高亮（与本次圈选区分），点击弹出词条卡；可在阅读设置里关闭。
- 从词条回到原文时，跳到那条原句、滚到眼前、句子底色高亮，顶部提示“来自词条 × · 回词条”，高亮保留到点击别处。
- 复习只做浏览式：词条列表逐条看、按文章重读；不做卡片翻转型逐条过，也不做自测。
- 只记录词条与文章的“最近打开”时间，用于首页继续复习与列表次级排序；不做复习次数、连续天数与正确率。

## 已确认的运行方式与首批资料准备

- 用户配置自己的模型服务，包括接口地址、密钥和模型名称；配置可以修改和切换。
- 文章、词条、原句、个人指令与笔记保存在 Windows 本机，并支持导出备份与恢复。
- 阅读和查看已保存内容支持离线使用；模型调用仍按用户配置的服务及所选学习上下文进行。
- 首批 21 份 PDF 先集中提取、核对成文章库，再接入软件供用户阅读。先完成固定材料与学习流程，再考虑通用 PDF 导入。

## 已确认的技术方案

- 桌面形态为 Electron 45 + TypeScript：界面用 Chromium，模型调用的 `@earendil-works/pi-ai@1.5.2` 跑在主进程（Electron 内置 Node 24.22.3，满足该包 Node ≥22.19 的要求）。
- 本地数据存 SQLite 单库，覆盖文章、词条、原句、学习指令、学习内容与模型配置；源 PDF 不入库，按 SHA-256 与页码引用。
- API 密钥用 Windows DPAPI（Electron `safeStorage`）单独加密保存，默认不进备份；备份为数据库快照，恢复整体替换，替换前自动留一份当前快照。
- 首个真实接入路径为 OpenAI 兼容接口，地址、模型名与密钥在软件内填写；验证流式增量、中途停止、错误提示与部分结果保留。
- 首批接入只支持一套服务也可工作，但配置允许多套保存与切换。

详见 [ADR 0001](./adr/0001-desktop-stack-and-local-data.md)。

## 已确认的首批文章库

- 21 份 PDF 提取为 63 篇文章：每套长篇匹配 1 篇、仔细阅读 2 篇（Passage One / Two）；题干、选项、答案、解析、听力、选词填空与翻译不入库。
- 正文按版面模板从文字层提取，不做 OCR；本批不引入 MinerU，保留为个别异常页的备用手段。
- 63 篇正文中的 88 条中文夹注剥离为“原文注释”，挂在对应词上；阅读时默认以浅色小字显示，可关闭。
- 每篇按段落与句子切分；句子持久化段内字符区间与页码，作为原句、出处与原文定位的单位。
- 语料以 JSON 存入 `docs/corpus/`（manifest、每篇一文件、核对清单），源 PDF 留在本机不入库。

详见 [语料说明](./corpus/README.md) 与 [ADR 0002](./adr/0002-first-batch-article-corpus.md)。

## 交互原型验证

2026-11-16，用户实际体验原型后反馈“可以，没什么问题”。原型所展示的阅读、原句收集、词条回查和自由学习流程，可以作为首版交互细化的基线。

原型使用示例材料与示例回复；真实 PDF 解析、真实模型接入和持久化保存仍需后续实现与验证。

## 首版范围外

- 在软件中作答、提交试卷或选择题选项。
- 试题标准答案管理、判题与评分。
- 错题本、错题分析、刷题与考试成绩统计。
- 首批 21 份以外的 PDF、其他考试和旧版试卷。
- 选词填空的空缺正文、听力原文、作文和翻译材料，暂不纳入首批文章范围。
- 面向任意新 PDF 的通用导入界面与通用解析流程。

原 PDF 保留用于对照和来源回查；正文以外的内容已在提取时隔离，63 篇的人工核对待进行。
