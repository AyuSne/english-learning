# 首版产品范围

更新日期：2026-11-16。

本文件记录已确认的产品范围。后续规划与实现以此处的最新决定为准；调研报告中的题型、题目与答案分析属于历史材料研究，不自动构成功能要求。

## 已确认

- 首版面向六级备考，使用平台为 Windows。
- 核心围绕文章和单词之间的联系：阅读文章、主动选词、保留原句与完整原文的关联，并在复习时回到阅读语境。
- 选词由学习者发起，支持单个词和短语；既包括不认识的表达，也包括认识但觉得值得学习的表达。
- 复习可以从词汇记录回到原文，也可以通过重读原文再次遇见所选词。
- PDF 是当前重点讨论的文章来源。导入目标调整为整理可阅读、可选词、可回查来源的文章。
- 首批材料限定为 2023—2026 年的 21 份六级 PDF，逐份清单及 SHA-256 见 [首批材料清单](./first-batch-pdfs.json)。
- 首批正文范围为仔细阅读和长篇匹配的完整英文文章。题干、选项、考试说明、答案和解析不进入文章库。
- 本轮仍以形成双方认可的首版产品说明为目标。

## 已确认的阅读与选词体验

- 主要阅读界面显示重新排版的文章正文，支持调整字号和行距，并保留打开原 PDF 对照的入口。
- 默认沿用先阅读圈词、后集中查词的节奏。阅读时圈选词或短语，正文做高亮，并保存对应原句与出处。
- 读完文章后可进入本篇选词列表，集中查词和整理学习内容。

## 已确认的词条组织与收集体验

- 同一个词或短语归到一个词条下，词条关联多条来自不同阅读语境的原句，分别保留出处与返回文章的关系。
- 常见词形变化归到同一词条，例如 approach、approached、approaching；原句和其中的实际词形保留原样。approachable 这类派生词独立成词条。
- 同一篇文章、同一句话中重复圈选同一表达，只保留一条原句关联；遇见新的原句时增加收藏。
- 原句不断积累的“收集感”是用户特别强调的核心体验。词条展示已收集原句条数和来源文章数；每次新增时，清楚展示刚收下的原句。

## 已确认的 LLM 辅助方向

- LLM 接受学习者自己的要求，任务和输出形式保持可定制，不将学习辅助固定为统一的语境词义讲解。
- 学习对象可以是一个词、短语、原句，或学习者选定的一组词。
- 用户希望按需获得词义、简单例句、相近短语、近义词、多义词说明、各种助记，以及包含多个目标词的文章等学习内容。
- 用户可保存自己的常用学习指令，之后调用、修改和复用。
- 生成结果先展示，由用户挑选、修改后保存到对应词条；用户可以继续生成或改写，再留下喜欢的内容。
- 用一组词生成的文章可以保存到文章库，明确标注“AI 生成”，并支持阅读、选词和回链。
- 首批外部导入材料仍为既定 21 份 PDF；生成文章是围绕所收词汇制作的学习材料，不扩展外部 PDF 范围。
- 各类学习内容保留来源信息。AI 直接生成的例句属于生成内容；在生成文章中阅读选词形成的原句记录，以该生成文章为来源。

## 已确认的自主复习与学习上下文

- 软件提供文章、词条、原句、个人学习内容和 LLM 工具的平台，复习内容与使用方式由学习者自主组合，不强制一条固定复习路线。
- 打开词条时默认先展示已收集的原句，释义、助记等学习内容可展开查看。默认展示顺序不限制用户采用其他复习方式。
- 调用 LLM 时，默认带上学习者选中的词和原句；其他原句、文章段落与已保存笔记由学习者选择是否加入。
- 学习上下文可查看、可选择，便于学习者控制模型这次参考的材料。

## 首版范围外

- 在软件中作答、提交试卷或选择题选项。
- 试题标准答案管理、判题与评分。
- 错题本、错题分析、刷题与考试成绩统计。
- 首批 21 份以外的 PDF、其他考试和旧版试卷。
- 选词填空的空缺正文、听力原文、作文和翻译材料，暂不纳入首批文章范围。

原 PDF 保留用于对照和来源回查。导入时需识别并隔离正文以外的内容，具体解析和核对方式待验证。

## 对后续讨论的影响

- 文章提取优先检查字词准确、段落与跨页完整性，以及原句和来源关系。
- MinerU 是候选解析方案；比较重点为文章提取与来源定位，不以题目、选项或答案解析为验收目标。
- 导入、展示与数据结构围绕文章、选词及其语境组织。

## 尚待讨论

- 如何在首批 21 份中准确识别完整阅读正文，并隔离非正文内容。
- 原 PDF 对照入口的具体交互，以及回到所选表达的定位方式。
- MinerU 与现有提取方式的样本效果比较，以及保留哪些定位信息。
- 词条与原句列表的具体展示、查找和修改交互，以及遇到归并错误时如何调整。
- 学习指令和上下文选择的具体交互，以及模型接入方式。
- 已保存学习内容与生成文章的具体编辑和查找交互。
- 词汇复习与重读文章的具体交互。
