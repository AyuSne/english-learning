# 首批文章库用模板提取，暂不引入 MinerU

2023—2026 年 21 份六级 PDF 的文字层干净、版式统一（Part III 下 Section B 长篇匹配、Section C 两篇仔细阅读），用 PyMuPDF 按模板切分成 63 篇：中文夹注剥离为注释层，句子切分后记录段内偏移与 PDF 页码，逐句可在源页文字层原样找回。本批不跑 MinerU 对比，保留为个别异常页的后备手段。

## Considered Options

- **MinerU 全量对比**：它解决扫描件、复杂版式与图表，本批没有这些情况；部署与调试成本换不回正文质量。
- **只存页码、不切句**：原句是核心资产，必须能稳定引用、能回到原文定位，句子需在导入时固定下来。
- **夹注留在正文**：会污染选词、分词与发给模型的上下文，且中文混进英文正文后难以再分离。

## Consequences

- 版面变化或换年份时，模板要更新；`check-corpus.py` 与核对清单是发现偏差的手段。
- 语料 JSON 入仓（可 diff、可重跑），源 PDF 不入仓，按 SHA-256 与页码引用。
- 源文本自身的缺字、缺标点按原样保留，不擅自修补。
