# 界面 token 表

更新日期：2026-11-17。实现直接照抄本表；数值的一手依据见 [阅读界面的第一手依据](./research/reading-ui-primary-sources.md)，本表只给结论。

## 1. 颜色

对比度是对着同列的底色实测的（WCAG 公式，不四舍五入）。正文与 12px 以上的文字一律 ≥4.5:1。

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#FBFAF3` | `#1A1A1E` | 页面底 |
| `--panel` | `#FFFEF9` | `#22221F` | 卡片、输入框、弹层 |
| `--sunken` | `#F8F5EC` | `#141416` | 侧栏、抽屉、条目底 |
| `--ink` | `#1A1A17`（16.67） | `#E8E4DA`（13.67） | 正文与标题 |
| `--ink-2` | `#6E6A5E`（5.16） | `#A8A29A`（6.86） | 次级文字、出处行、提示 |
| `--ink-3` | `#A9A399` | `#6E6A62` | 禁用态、占位符；**不承载信息** |
| `--amber` | `#8F5A1A`（5.51） | `#D9A441`（7.71） | 已收集、钉住、强调 |
| `--amber-underline` | `#8A6A28`（4.81） | `#C9A15A`（7.21） | 已收集的虚线下划线 |
| `--blue` | `#2F5FA8`（6.04） | `#7FA7E8`（7.10） | 稍后看 |
| `--bed-select` | `#F2E4BE` | `#4A3B1E` | 本次选中（上面写 `--ink`：13.8 / 11.4） |
| `--bed-pin` | `#FBF2DC` | `#332A15` | 钉住标签、钉板新卡 |
| `--line-pin` | `#E3D3AE` | `#5A4A2A` | 钉住卡片描边 |
| `--danger` | `#B4432A`（5.31） | `#E08A72`（7.0） | 丢弃、停止、错误标题 |
| `--danger-bed` | `#FDF4EE` | `#2E1F1A` | 错误块底 |
| `--rule` | `#E6E0D0` | `#33322D` | 分隔线、边框 |
| `--hover` | `#F3EEE1` | `#2A2A26` | 悬停底 |

规则：

- 琥珀只做强调与小面积文字，**不做大段正文色**；要更亮就换 `--ink`，不要调琥珀。
- 提示类小字一律 `--ink-2`。原型里出现过的 `#9A9384` 只有 2.92:1，作废。
- 词状态三色固定：已收集 `--amber` + 下划线 `--amber-underline`、稍后看 `--blue`、本次选中 `--bed-select`；不再加第四色。
- 深色不用纯黑，`--paper` 用 `#1A1A1E`。

```css
:root{
  --paper:#FBFAF3; --panel:#FFFEF9; --sunken:#F8F5EC;
  --ink:#1A1A17; --ink-2:#6E6A5E; --ink-3:#A9A399;
  --amber:#8F5A1A; --amber-underline:#8A6A28; --blue:#2F5FA8;
  --bed-select:#F2E4BE; --bed-pin:#FBF2DC; --line-pin:#E3D3AE;
  --danger:#B4432A; --danger-bed:#FDF4EE;
  --rule:#E6E0D0; --hover:#F3EEE1;
}
[data-theme="dark"]{
  --paper:#1A1A1E; --panel:#22221F; --sunken:#141416;
  --ink:#E8E4DA; --ink-2:#A8A29A; --ink-3:#6E6A62;
  --amber:#D9A441; --amber-underline:#C9A15A; --blue:#7FA7E8;
  --bed-select:#4A3B1E; --bed-pin:#332A15; --line-pin:#5A4A2A;
  --danger:#E08A72; --danger-bed:#2E1F1A;
  --rule:#33322D; --hover:#2A2A26;
}
```

## 2. 字体

| 场景 | 字体栈 |
| --- | --- |
| 阅读正文（英文） | `"Source Serif 4", Sitka, Georgia, "Songti SC", serif` |
| 界面 | `"Segoe UI Variable", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif` |

- Source Serif 4（OFL、可变）随包分发，不依赖系统；不写 `"Sitka Text"`（20px 已超出它的 9.5–13.5pt 光学区间）。
- 中文界面文字用 Microsoft YaHei UI，最小 12px。
- 标题、词条名、篇名可用衬线（`serif` 栈）；按钮、标签、正文之外的界面文字一律无衬线。
- 正文不加字距；大写小标签 `letter-spacing:.06em`。

## 3. 字号与行高

阅读（四档字号、三档行距，记住用户选择）：

| 档位 | 值 |
| --- | --- |
| 字号 | 16 / 18 / **20** / 22 px |
| 行高 | 1.6 / **1.8** / 2.0 |

行列宽 620px；段间距 1em；英文首行不缩进；中文长段落行高 1.75；两端对齐关闭。

界面梯度：

| 角色 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| caption | 12 / 16 | 出处行、角标、提示 |
| small | 13 / 18 | 次级按钮、列表副标题 |
| body | 14 / 20 | 界面正文 |
| chat | 15 / 27 | 对话正文 |
| section | 16 / 24 | 小标题 |
| title | 20 / 28 | 页内标题 |
| display | 23 / 32 | 页面主标题 |

## 4. 间距

4 / 8 / 12 / 16 / 24 / 32 / 48。

角色固定值：页面左右 32；卡片内 12–16；列表项间距 8；区块之间 24；对话消息之间 22–26；输入框内 10–14。

## 5. 圆角与阴影

| 用途 | 圆角 |
| --- | --- |
| 小标签、角标 | 4 |
| 按钮、输入、下拉 | 8 |
| 卡片、卡片内块 | 10 |
| 气泡、弹层、抽屉 | 14 |
| 胶囊（chip、开关） | 999 |

| 层级 | 阴影 |
| --- | --- |
| 浮起（抽屉、浮钮） | `0 6px 20px rgba(60,48,30,.06)` |
| 弹层（钉住弹层、确认框） | `0 20px 50px rgba(40,32,20,.18)` |

深色下阴影改为 `rgba(0,0,0,.45)` 与 `rgba(0,0,0,.6)`，靠 `--panel` 提亮区分层级。

## 6. 布局

| 场景 | 尺寸 |
| --- | --- |
| 阅读正文列 | 620 |
| 对话列 | 760 |
| 线程栏 | 236 |
| 钉板抽屉 | 336（收起 44） |
| 管理页三栏 | 240 / 1fr / 320 |
| 页边栏（阅读注文） | 200，≥1000px 显示 |

断点：<1100px 管理页收成两栏（右栏改抽屉）；<1000px 阅读页的页边注改为行内展开；<900px 线程栏改抽屉。

## 7. 状态

- 悬停：底 `--hover`，边框加深一档（`--rule` → `#CFC5AF`）。
- 焦点：`outline:2px solid var(--amber); outline-offset:2px`，不用默认蓝框。
- 选中（文字选区）：浏览器默认即可，不自定义。
- 禁用：`color:var(--ink-3)`，不加透明度，避免对比度二次衰减。
- 深色下所有 `<img>` 不加滤镜，图标用 `currentColor`。

## 8. 动效

- 悬停、聚焦 150ms `ease-out`；toast 180ms 淡入；抽屉 180ms 位移不超过 8px。
- 不做缩放、不做弹跳、不做视差。
- 尊重 `prefers-reduced-motion: reduce`：全部改为 0ms。
