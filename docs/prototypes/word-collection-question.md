# 原句收集与自由学习交互原型

这是用于产品讨论的临时原型，问题是：新增原句的反馈、同词合并和从词条返回文章，是否能体现用户强调的持续收集感与自主学习方式？

直接打开同目录 word-collection-prototype.html 即可体验。示例使用内存状态和自写的 AI 示范文章，不读取首批 PDF，不调用真实 LLM；“载入示例回复”仅用于体验编辑与保存流程。

可以自由操作，也可以走三条引导路径：收集新原句、重复圈选、保存生成文章再阅读。

已检查主要交互、桌面与窄窗口布局、浅色和深色显示。

## 用户反馈

2026-11-16，用户实际体验后反馈“可以，没什么问题”。原型展示的原句积累、词条回查与自由学习流程获认可，可作为首版交互细化的基线；该反馈不等于真实 PDF、模型或持久化功能已完成。
